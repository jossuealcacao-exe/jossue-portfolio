GPT‑5.6 se presenta en tres versiones: **Sol, Terra y Luna**. Los nombres ayudan a distinguirlas, pero lo importante es saber qué tipo de trabajo puede resolver cada una y cuánto tiempo necesitas esperar.

La actualización está disponible en ChatGPT, Codex y la API de OpenAI desde el 9 de julio de 2026. No hace falta usar siempre el modelo más potente. Para elegir, revisaría la dificultad de la tarea, el costo de un error y la facilidad para comprobar la respuesta.

## Sol para trabajos complejos

Sol es el modelo con mayor capacidad de la familia. Está pensado para tareas largas o con varias etapas: revisar una arquitectura, programar una función completa, comparar escenarios de negocio o coordinar herramientas.

Lo usaría cuando necesito que ChatGPT mantenga bastante contexto y revise supuestos antes de entregar una respuesta. En ecommerce, por ejemplo, puede ayudar a estudiar un flujo que conecta Shopify, analítica y CRM.

Para redactar un correo o resumir una nota breve, Sol suele ser más de lo necesario.

## Terra para el trabajo diario

Terra busca un equilibrio entre capacidad y costo. Puede preparar un brief, ordenar notas, analizar una tabla o crear la primera versión de una landing.

Empezaría con Terra en la mayoría de las tareas profesionales. Si el resultado necesita más análisis, cambiaría a Sol. Si el proceso está bien definido y se repetirá muchas veces, probaría Luna.

## Luna para tareas claras y repetitivas

Luna es la opción rápida y económica. Funciona mejor cuando la instrucción tiene límites precisos y el resultado se puede revisar fácilmente.

Puede servir para clasificar registros, extraer campos, resumir textos breves o generar varias versiones de un mismo contenido. Conviene darle una estructura, un ejemplo y el formato de salida esperado.

## Cómo los elegiría

- **Luna** para tareas repetitivas con resultados fáciles de comprobar.
- **Terra** para análisis, redacción y producción cotidiana.
- **Sol** para programación exigente, decisiones complejas o procesos con varias herramientas.

Antes de cambiar de modelo, revisaría la instrucción. Explicar el objetivo, añadir el contexto necesario y mostrar un ejemplo puede mejorar más la respuesta que subir de nivel.

## Qué cambia con los tres nombres

La clasificación facilita asignar capacidad según el trabajo. Un equipo puede usar Luna en procesos de volumen, Terra para las tareas habituales y reservar Sol para los casos donde una respuesta incorrecta cuesta más tiempo o dinero.

Mi punto de partida sería Terra. Después compararía calidad, tiempo y costo con una tarea real. Esa prueba ofrece más información que elegir el modelo únicamente por su nombre.
