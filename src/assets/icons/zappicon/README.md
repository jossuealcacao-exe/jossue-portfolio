# Zappicon (curated subset)

Source: Zappicon v1.2 Free UI icons set — **1-Light** style only.

## Why this set

Apple-style “less is more”: icons mark **affordance**, never decorate every row.

| File | Role on site |
| --- | --- |
| `menu-bars.svg` / `xmark.svg` | Mobile nav open/close; lightbox close |
| `download-bracket.svg` | CV download |
| `arrow-left-small.svg` / `arrow-right-small.svg` | Lightbox prev/next; internal CTAs |
| `arrow-up-right-small.svg` | External destination; gallery open hint |
| `envelope.svg` | Email (contact channels) |
| `chat-dots.svg` | WhatsApp (contact channels) |

## Rules

- Labels stay primary; icons are decorative (`aria-hidden`) unless the control is icon-only (menu).
- Do not add nav icons, status icons, hero ornaments, or icon rows.
- Prefer Light over Regular/Filled/Duotone for this editorial UI.
- Color via `currentColor` only; do not redistribute the full pack.
