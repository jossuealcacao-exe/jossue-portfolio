# Marca

Deposite aquí únicamente activos de identidad oficiales: logotipos, variantes, paleta,
manual, tono y reglas de uso.

## Formatos

- Preferir SVG original para vectores; adjuntar PNG solo como referencia.
- Manuales en PDF y fuentes editables disponibles; especificaciones en Markdown.
- Conservar nombres descriptivos y registrar versión o vigencia.

## Confidencialidad

No asumir que un activo recibido puede publicarse. Documente autor, licencia, permiso y
restricciones. El **Zappicon no está disponible**: permanece faltante y no debe sustituirse,
trazarse ni reinterpretarse.
