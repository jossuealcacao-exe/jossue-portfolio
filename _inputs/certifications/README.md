# Certificaciones

Deposite credenciales relevantes con nombre oficial, entidad emisora, fecha de emisión,
vencimiento, estado y método de verificación.

## Formatos

- Inventario en CSV o Markdown.
- Evidencia en PDF, PNG o URL oficial estable.
- Indicar si el nombre de la certificación requiere marca o grafía exacta.

## Confidencialidad

Redacte identificadores, códigos QR privados y datos personales innecesarios. Una credencial
válida aún requiere aprobación antes de exponer su comprobante o URL de verificación.
