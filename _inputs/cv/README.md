# CV

Deposite el currículum vigente y, si existe, una fuente editable. Debe permitir verificar
experiencia, educación, capacidades y fechas sin convertir inferencias en hechos.

## Formatos

- PDF para revisión y DOCX o Markdown para edición.
- Mantener una copia original privada y una versión preparada para publicación.
- Indicar fecha de actualización y responsable de validar el contenido.

## Confidencialidad

Elimine de la versión pública domicilio, teléfono, identificadores, firmas y referencias
privadas. Un CV recibido no queda automáticamente aprobado para descarga pública.
