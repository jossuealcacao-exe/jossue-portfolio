# Analítica

Deposite objetivos de medición, decisiones de proveedor, propiedad de cuenta, línea base,
criterio de consentimiento, retención y evidencia de pruebas de eventos.

## Formatos

- Decisiones y criterios en Markdown.
- Exportaciones o líneas base en CSV con periodo, fuente y exclusiones.
- Capturas redactadas solo como evidencia complementaria.

## Confidencialidad

No incluya contraseñas, secretos, tokens ni identificadores en documentación pública. No hay
proveedor ni IDs definidos. La medición no debe activarse hasta validar privacidad,
consentimiento, minimización y responsable.
