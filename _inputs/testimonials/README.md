# Testimonios y prueba social

Deposite citas, referencias y logos autorizados. Cada testimonio debe conservar texto
original, nombre, cargo, relación con el trabajo, contexto y evidencia de aprobación.

## Formatos

- Citas y metadatos en Markdown o DOCX.
- Logos oficiales en SVG o PNG junto con el permiso de uso.
- Evidencia de consentimiento en PDF o exportación legible del mensaje.

## Confidencialidad

No fabrique, combine ni cambie el sentido de citas. Datos de contacto y mensajes completos
son confidenciales. La relación profesional no implica permiso para usar nombre, cargo o logo.
