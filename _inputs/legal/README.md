# Legal y permisos

Deposite criterios de privacidad, licencias, consentimientos y aprobaciones de publicación.
Esta carpeta debe permitir rastrear quién autorizó qué contenido y bajo qué condiciones.

## Formatos

- PDF o exportación legible para autorizaciones; Markdown para índices y resúmenes.
- CSV o Markdown para inventario de derechos de activos.
- Registrar alcance, aprobador, fecha, vigencia y restricciones.

## Confidencialidad

Trate contratos, correos, firmas y datos de responsables como confidenciales. No interprete
este README como asesoría legal; el criterio aplicable requiere una persona responsable.
