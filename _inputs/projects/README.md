# Proyectos

Deposite el inventario de proyectos candidatos y sus datos fuente: propósito, rol, periodo,
tecnologías, estado, enlaces y condiciones de publicación.

## Formatos

- Inventario en CSV o Markdown.
- Una ficha Markdown por proyecto, sin asumir slug ni ruta pública.
- Enlaces a repositorios o demos con propietario, visibilidad y fecha de revisión.

## Confidencialidad

Marque NDA, repositorios privados, proyectos internos y material de terceros. Antes de
enlazar una demo o repositorio, revise secretos, datos reales, licencias y vigencia.
