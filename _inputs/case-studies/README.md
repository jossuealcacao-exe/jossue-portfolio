# Casos de estudio

Deposite fuentes narrativas y evidencia para cada caso: contexto, problema, objetivos,
audiencia, restricciones, rol, equipo, proceso, decisiones, resultados y aprendizajes.

## Formatos

- Una carpeta por nombre interno; narrativa en Markdown.
- Referenciar capturas y métricas guardadas en sus directorios especializados.
- Adjuntar fuentes de verificación y estado de aprobación.

## Confidencialidad

No publicar nombres, logos, procesos, cifras ni pantallas sin permiso documentado. La
selección e integración del primer caso está pendiente de validación; no se asume terminada.
