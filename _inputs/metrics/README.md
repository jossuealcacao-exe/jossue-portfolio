# Métricas

Deposite resultados cuantitativos o cualitativos con definición, valor, unidad, fuente,
periodo o fecha de corte, responsable y permiso de publicación.

## Formatos

- CSV para series o tablas; Markdown para definiciones y contexto.
- Capturas o exportaciones de la fuente como evidencia, nunca como único dato editable.
- Mantener un diccionario que distinga usuarios, cuentas, sesiones, páginas y entregables.

## Confidencialidad

Los datos proporcionados de Bloqio Builder —**57 usuarios y 45 páginas**— no son
publicables: no tienen fecha de corte, definición, fuente validada ni autorización. Deben
permanecer confidenciales hasta completar esas validaciones.
