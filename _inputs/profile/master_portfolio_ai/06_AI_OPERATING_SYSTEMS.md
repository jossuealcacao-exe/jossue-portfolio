## Resumen público — Español

Diseñé un Sistema Operativo modular para crear, optimizar, auditar, adaptar y transferir prompts entre modelos y agentes. El sistema conserva intención, reduce ambigüedad, define autoridad, adapta instrucciones a cada plataforma y valida la salida antes de considerarla terminada.

## Public summary — English

I designed a modular AI Operating System for creating, optimizing, auditing, adapting, and transferring prompts across models and agents. The system preserves intent, reduces ambiguity, defines authority, adapts instructions to each platform, and validates outputs before they are considered complete.

## AHP — Agent Handoff Protocol

AHP permite transferir trabajo entre agentes sin perder:

- intención;
- estado;
- decisiones;
- restricciones;
- archivos;
- riesgos;
- validaciones;
- próxima acción.

El protocolo fue usado de forma real dentro de Bloqio Builder mediante handoff points y documentación append-only.

## Diferenciador

Un “SO de IA” no es un prompt largo. Es una arquitectura que separa:

- reglas persistentes;
- contexto temporal;
- modos;
- contratos;
- fuentes;
- autoridad;
- memoria;
- QA;
- handoff;
- cambios de versión.
