# Perfil

Deposite biografías, retrato, habilidades priorizadas, idiomas y datos de posicionamiento
confirmados. No use este directorio para definir rutas públicas.

## Formatos

- Textos en Markdown o TXT, separados por idioma y extensión.
- Retrato en JPG, PNG o AVIF de alta resolución, con crédito si aplica.
- Datos estructurados en CSV o Markdown con fuente y vigencia.

## Confidencialidad

No infiera cargo, ubicación, disponibilidad ni dominio. La URL pública y canonical siguen
sin definir y requieren validación explícita antes de aparecer en metadatos.
