# Capturas y evidencia visual

Deposite pantallas, diagramas y artefactos visuales que ayuden a explicar proyectos o casos.
Incluya inventario, orden narrativo, contexto y una propuesta de texto alternativo.

## Formatos

- PNG para interfaces nítidas; JPG o AVIF para fotografía; SVG para diagramas propios.
- Conservar originales y crear copias redactadas por separado.
- Usar nombres descriptivos; evitar nombres genéricos como `final-2`.

## Confidencialidad

Revise cada imagen a tamaño completo. Oculte datos personales, credenciales, claves, URLs
internas y contenido de clientes. Confirme derechos de terceros y permiso antes de publicar.
