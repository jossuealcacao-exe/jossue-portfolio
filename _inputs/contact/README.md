# Contacto

Deposite canales que puedan sostener el llamado a la acción: correo o formulario,
enlaces profesionales, disponibilidad y nivel de ubicación autorizado.

## Formatos

- CSV o Markdown con etiqueta, valor/URL, propósito, vigencia y permiso.
- Para zona horaria, preferir un identificador IANA; la ubicación exacta es opcional.
- Documentar quién recibe y mantiene cada canal.

## Confidencialidad

No hay un contacto público proporcionado. No invente correo, teléfono, formulario o perfil.
No publique domicilio, teléfono personal ni datos de terceros; valide primero el destino.
